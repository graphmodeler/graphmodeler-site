# The title bar

The strip across the top of the window has the name of the program on the left and four controls on the right. It is the same on every tab.

<img class="shot shot-light" src="/shots/title-bar-light.png" alt="The title bar, with the name of the program on the left and the Dark mode switch, the Simple mode switch, the About button and the help button on the right">
<img class="shot shot-dark" src="/shots/title-bar-dark.png" alt="The title bar in the dark theme">

In a window less than 760 pixels wide, the switches and the About button show only their icons.

## Dark mode

The first switch, **Dark mode**, with a moon beside it, changes the whole window between the light and the dark theme. The program starts in the theme your
computer uses, and after you have pressed the switch it remembers your choice, on this computer. The theme is not saved in a project, so a project you send to someone else
does not change their window. Diagrams and the pictures the program publishes are not affected.

## Simple mode

The second switch, **Simple mode**, with a play button beside it, puts the window in [Simple mode](/docs/simple-mode/): a smaller window for someone who is given a finished model, chooses
a data file, types a value or two and presses Run. It has the three **Output** tabs, **Diagram**, **Knowledge Graph** and **DOT**, and none of the controls that change the project. Press the switch again to bring everything back.

The switch always does what it says, so the quickest way to see what it does is to press it, as with dark mode.

- **The window starts in Full mode**, every time the program starts. Simple mode is not remembered between launches, and pressing the switch never changes the project file.
- **A project can ask to be opened in Simple mode.** An author sets that when they [save a copy for sharing](/docs/sharing/). Opening such a file switches the window for you.
- **New leaves Simple mode.** A new project is empty, and there is nothing to run in it, so **New** puts the window back in Full mode, where a project is built. So does opening a project that has nothing in it.

## About

The **About** button, with an "i" beside it, opens [the About page](/docs/about/) in the place of the tabs: the version, the license and the credits. It is there in Full and Simple mode. While the page is open, the button looks chosen and no tab does. Choosing a tab leaves the page.

## The help button

The button with the question mark opens the home page of this website in your browser. Each tab has a help button of its own, at the right end of its row of buttons, that opens the page about that tab.
