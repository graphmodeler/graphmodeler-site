# Examples and techniques

Worked examples, each built from a real model. Every one shows the diagram you can zoom and hover, explains how it was put together, and has the project and its data to
download and open in Graph Modeler, so that you can change it and see what happens. New ones are added from time to time; the [feed](/feed.xml) tells you when.

<ExampleList />

Graph Modeler is free for personal, educational, research and other non-commercial use. Using it for client work or at a company needs a [commercial license](/pricing/). The
examples use invented data, so that you can use them freely to learn.
